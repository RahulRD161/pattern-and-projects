# Logic to Code

🚀 Collection of **JavaScript patterns, problem-solving exercises, and mini-projects** like Tic-Tac-Toe.  
Showcasing logical thinking, clean coding, and fundamentals of web development (HTML, CSS, JS).

---

## 📖 About

This repository is my **coding playground** where I practice:

- Pattern programs in JavaScript  
- Logical & problem-solving exercises  
- Fun mini web projects (like Tic-Tac-Toe)  

The goal is to **strengthen problem-solving** and **showcase practical coding skills**.

---

## ✨ Features

- 🔢 Multiple **pattern programs** (triangles, pyramids, number patterns, etc.)  
- 🎮 Mini-projects like **Tic-Tac-Toe**  
- 🎯 Focus on **logic, clean code, and reusability**  
- 🌐 Built with **HTML, CSS, JavaScript**
